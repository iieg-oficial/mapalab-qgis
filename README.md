# mapalab-qgis

Complemento de QGIS con el catálogo de capas de mapalab.

```bash
make zip    # dist/mapalab-qgis-<version>.zip para «Instalar a partir de ZIP»
make link   # enlaza el repo al perfil de QGIS para desarrollar
```

La documentación vive en [context-ame-esta](https://github.com/iieg-oficial/context-ame-esta).
