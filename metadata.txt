about=Brings the MapaLab layer catalog of the Institute of Statistical and Geographic Information
    of Jalisco (IIEG, Mexico) into QGIS: the same theme tree, an accent-insensitive search and the
    institutional metadata. Layers are added as tiled WMS for viewing and can be downloaded as
    GeoPackage for analysis, filtered by municipality and date. Click a feature to copy it with its
    attributes, switch between IIEG and INEGI boundaries, and open maps shared from the web viewer.
    Read only.

    Requires network access to the MapaLab server of the IIEG, already set to
    https://iieg.jalisco.gob.mx. No external Python dependencies.

    Lleva a QGIS el catálogo de capas de MapaLab del IIEG Jalisco: el árbol de temas, el buscador y
    la metadata institucional. Las capas entran como WMS y se descargan como GeoPackage, filtradas
    por municipio y fecha.
